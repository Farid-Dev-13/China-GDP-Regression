# China GDP Regression Analysis

This is my first Machine Learning project, where I explore China's historical GDP data and compare different regression techniques.

## Models

- Linear Regression
- Polynomial Regression (Degrees 2–5)
- Exponential Regression
- Sigmoid Regression

## Evaluation Metrics

- R² Score
- Mean Absolute Error (MAE)

## Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- SciPy

## Dataset

The dataset was obtained from Jadi's Machine Learning with Python course.

- [Course – Maktabkhooneh](https://maktabkhooneh.org/course/یادگیری-ماشین-پایتون-mk1318/)
- [Dataset – GitHub](https://github.com/jadijadi/machine_learning_with_python_jadi/blob/main/china_gdp.csv)

## Project Structure

- `china_gdp_prediction.ipynb`: Main project notebook
- `china_gdp.csv`: Dataset
- `requirements.txt`: Required Python libraries

## Note

This project is an educational exercise. The models are evaluated using a random train-test split, so the results should not be interpreted as a reliable measure of future GDP prediction performance.
